Method

Every step below is the code path the judges' case runs through. Nothing is looked up from a stored dataset.

  1. i

    Input

    T1, T1Gd, T2, FLAIR on one grid. A single 4-channel file is split on the server.

  2. ii

    Checks

    Readable, 3D, finite, non-constant, ≤ 1 GB, matching shape and affine, skull-stripped heuristic.

  3. iii

    Model

    Reorient to RAS, resample to 1 mm, z-score per channel; SegResNet (MONAI, Apache-2.0) outputs TC, WT, ET.

  4. iv

    Labels

    Inverted back to the uploaded grid and affine; written as BraTS codes 1 · 2 · 4.

  5. v

    Volume

    V = N × Δx·Δy·Δz
    mL = mm³ ÷ 1000

  6. vi

    Output

    NIfTI label map, 3D + linked-slice viewer, HTML/PDF report with provenance.

    Privacy and Security

    Every upload is deleted automatically. This is what the server holds right now, and when each item goes.

    Stored on this server

    RefWhatFilesSizeDeleted in
    Loading…

    File names are shown only for studies uploaded from this browser; other uploads appear as a count and size.

    1. Where. Uploads and everything made from them (sequences, label map, surfaces, report data) sit in one folder per study in the server's temporary directory, on the machine running Voxels.
    2. When. Each study is deleted 23 h after upload. The server checks at startup, on every access and every 10 minutes, so nothing outlives 24 h.
    3. What leaves. No cloud, analytics or AI-service code was found by the repository's leak audit (scripts/audit_no_leaks.py). The model runs on this machine.
    4. Who can open a study. Only someone holding its link: each study ID is 128 random bits. There are no accounts, so do not share links and upload only public, de-identified research data.
    Voxels

    Research and teaching prototype. Outputs are suspected tumour regions predicted by the model and estimated volumes. Not a diagnosis; not clinically validated; not for clinical use.

    Model

    MONAI brats_mri_segmentation v0.5.4, SegResNet (Myronenko, 2018). Apache-2.0.

    Data

    Medical Segmentation Decathlon (Antonelli et al., 2022), derived from BraTS (Menze et al., 2015; Bakas et al., 2017, 2018). Public, de-identified.
